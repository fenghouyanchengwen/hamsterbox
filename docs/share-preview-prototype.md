# 分享包只读预览原型

| 项目 | 内容 |
|---|---|
| 负责人 | 成员五：分享包 |
| 状态 | 待评审的原型，依赖格式与导出草案 |
| 更新日期 | 2026-11-12 |

`preview_share_package` 接收 `.hbox` 的字节，返回已校验的 manifest 和封面警告。它不会把 ZIP 解压到磁盘，也不会修改数据库。可直接校验导出原型的输出。

## 已实现的检查

- 限制压缩包大小、条目数和解压后总大小；只接受根目录的 `manifest.json` 和已引用的 `covers/` 图片。
- 拒绝路径穿越、重复路径或 JSON 字段、符号链接、加密条目、不支持的压缩方式、UTF-8 BOM 和损坏的 manifest。
- 使用分享包 Schema 校验格式版本、字段、评分和评价模式，并检查条目、资源和标签引用关系及资源文件名。
- 校验封面内容的长度、SHA-256、路径、扩展名、声明的媒体类型和文件头；缺失或失败时返回警告，不丢弃其余元数据。文件头检查不等同于完整图片解码。

## 仍需完成

- 预览结果尚未接入 HTTP、桌面端或前端；显示时仍需安全处理用户提供的文本。
- 暂未匹配本地资源，也不显示自动匹配、缺失和冲突的完整交互；未实现导入、事务提交或回滚。
- 来源资料库标识、冲突规则、大小上限、封面处理及 Schema 打包方式仍需评审。
- 预览结果不验证远端资源文件本身，因为默认分享包不包含原始媒体；SHA-256 匹配需要接收方选择或扫描本地文件后执行。

## 校验

安装后端依赖后，在仓库根目录运行：
