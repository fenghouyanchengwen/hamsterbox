# 标签与评分契约 v1

| 项目 | 内容 |
|---|---|
| 用途 | 冻结条目、标签分类、标签、评分与评价的数据边界 |
| 负责人 | 成员三：张亦弛 |
| 状态 | 已定稿 |
| 最后更新 | 2026-11-01 |

## 1. 范围

本契约覆盖：

- 本机标签分类的创建和维护规则；
- 标签的创建、修改、删除和选择；
- 条目与标签的关联；
- 每个标签维度上的 1 至 10 分评分；
- 每个条目唯一的整体评价文字；
- 分享包中标签、评分、原评价和附加评价的边界；
- 分享导出时临时派生条目的处理规则。

本契约不覆盖：

- 通用关键词搜索的 SQL 实现；
- 前端视觉样式；
- 原始媒体文件的移动、删除或重命名；
- 分享包压缩格式的具体实现；
- 标签分类初始预置名单的最终产品文案。

## 2. 核心定义

### 2.1 条目 Entry

条目是本地资料库中的最小评价单位，代表一个作品。

一本书、一部电影、一个游戏或一季电视剧各可以被建立为一个条目。一个条目可以关联多个本地资源，例如视频、字幕、PDF 和图片。标签、标签评分和整体评价都记录在条目层面。

### 2.2 资源 Resource

资源是条目关联的一个本地文件。资源不是评价单位。

同一个条目的多个文件不会被自动拆成多个条目。拆分只在分享导出时发生。

### 2.3 标签分类 TagCategory

标签分类是只保存在本机的管理分组。分类拥有名称、可选颜色和排序信息。

分类和颜色都不同步到其他用户的资料库。分享包中的标签被导入时，由接收方选择要放入自己的哪个本地分类。

### 2.4 标签 Tag

标签是分类下的可选分类项，例如“科幻”“剧情”。标签不保存颜色，也不保存跨设备分享标识。

### 2.5 条目标签关系 EntryTag

EntryTag 连接一个条目和一个标签，并在该关系上保存一个可选的 1 至 10 分评分。

同一对 `entry_id` 和 `tag_id` 只能存在一条关系。同一标签名可以出现在不同分类中，但同一分类内不能出现两个规范化名称相同的标签。

### 2.6 评价 Review

每个条目最多保存一份整体评价文字。该文字不属于标签，也不随标签删除而删除。

标签各有独立评分，但标签不分别保存评价文字。

## 3. 数据模型

### 3.1 Entry

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | 整数 | 本地主键 |
| `share_id` | UUID | 条目跨设备分享标识 |
| `title` | 字符串 | 去空格后 1 至 200 字符 |
| `type` | 枚举 | `game`、`book`、`video`、`audio`、`image`、`model`、`other` |
| `description` | 字符串或空 | 最多 20000 字符 |
| `review` | 字符串或空 | 整个条目唯一的一份评价文字，最多 10000 字符 |
| `lifecycle_state` | 枚举 | `library` 或 `temporary`，默认 `library` |
| `cover_path` | 字符串或空 | 仅后端使用，不在响应中泄露绝对路径 |
| `created_at` | UTC 时间 | 创建时间 |
| `updated_at` | UTC 时间 | 修改时间 |

### 3.2 TagCategory

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | 整数 | 本地主键 |
| `name` | 字符串 | 去空格后 1 至 32 字符；分类间大小写不敏感唯一 |
| `color` | 字符串或空 | 可选本地颜色，格式为 `#RRGGBB` |
| `sort_order` | 整数 | 默认按升序排列 |
| `system_key` | 字符串或空 | 用户分类为空；系统“未分类标签”固定为 `uncategorized` |
| `created_at` | UTC 时间 | 创建时间 |
| `updated_at` | UTC 时间 | 修改时间 |

系统必须存在且只能存在一个 `system_key=uncategorized` 的分类。该分类不能删除，用户可见名称在 v1 固定为“未分类标签”。

除“未分类标签”外，首次启动的其他分类由可调整的种子配置创建。具体名单不属于本契约，也不得写入数据库唯一约束或业务枚举。

### 3.3 Tag

| 字段 | 类型 | 规则 |
|---|---|---|
| `id` | 整数 | 本地主键 |
| `category_id` | 整数 | 外键 TagCategory.id |
| `name` | 字符串 | 去空格后 1 至 32 字符 |
| `normalized_name` | 字符串 | 后端使用 `casefold()` 生成，不直接作为公开字段 |
| `created_at` | UTC 时间 | 创建时间 |
| `updated_at` | UTC 时间 | 修改时间 |

数据库必须为 `(category_id, normalized_name)` 建立唯一约束。Tag 不包含 `share_id`、`color` 或 `rating_enabled`。

### 3.4 EntryTag

| 字段 | 类型 | 规则 |
|---|---|---|
| `entry_id` | 整数 | 外键 Entry.id，条目删除时级联删除 |
| `tag_id` | 整数 | 外键 Tag.id |
| `rating` | 整数或空 | 可选，取值 1 至 10 |
| `created_at` | UTC 时间 | 关联创建时间 |
| `updated_at` | UTC 时间 | 评分或关联修改时间 |

主键为 `(entry_id, tag_id)`。EntryTag 不包含评价文字。

## 4. 业务规则

1. 条目按作品建立，一个作品对应一个本地评价单位。
2. 一个条目可以关联多个资源，但不能通过资源是否存在推断作品类型。
3. 一个条目最多一份整体评价文字，允许为空。
4. 一个条目可以拥有多个标签。
5. 一个标签在同一个分类内名称唯一，跨分类可以重名。
6. 同一对条目与标签只能关联一次。
7. 每个条目标签关系最多一个评分，评分允许为空或 1 至 10 的整数。
8. 添加标签不要求同时评分。
9. 删除仍被任一条目使用的标签必须返回冲突，不执行级联删除。
10. 删除仍包含标签的分类必须返回冲突；系统“未分类标签”分类始终禁止删除。
11. 删除标签分类或标签不得删除条目、资源文件或条目整体评价。
12. 标签分类颜色只保存在本机，不参与搜索和分享。
13. 所有时间以 UTC 保存；公开响应使用带时区的 ISO 8601 时间。
14. `lifecycle_state=temporary` 的条目不出现在正常列表、搜索和统计中。

## 5. HTTP 契约

### 5.1 标签分类

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/tag-categories` | 按排序返回本地分类 |
| POST | `/api/tag-categories` | 新建用户分类 |
| PATCH | `/api/tag-categories/{category_id}` | 修改名称、颜色或排序 |
| DELETE | `/api/tag-categories/{category_id}` | 删除空分类 |

创建分类请求：

```json
{
  "name": "内容题材",
  "color": "#5B8FF9",
  "sort_order": 10
}
```

### 5.2 标签

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/tags` | 查询标签，可按 `category_id` 筛选 |
| POST | `/api/tags` | 在分类中创建标签 |
| PATCH | `/api/tags/{tag_id}` | 修改标签名称或所属分类 |
| DELETE | `/api/tags/{tag_id}` | 删除未被使用的标签 |

创建标签请求：

```json
{
  "category_id": 1,
  "name": "科幻"
}
```

### 5.3 条目标签与评分

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/entries/{entry_id}/tags` | 返回条目的标签和当前评分 |
| PUT | `/api/entries/{entry_id}/tags/{tag_id}` | 创建或更新关联及评分 |
| DELETE | `/api/entries/{entry_id}/tags/{tag_id}` | 移除条目的标签关系 |

创建仅分类关系：

```json
{
  "rating": null
}
```

创建或更新评分：

```json
{
  "rating": 9
}
```

`PUT` 使用同一对条目和标签时执行幂等更新：不存在则创建，存在则更新评分。`DELETE` 只移除条目标签关系，不删除标签定义。

条目整体评价通过现有条目编辑接口 `PATCH /api/entries/{entry_id}` 的 `review` 字段更新。

## 6. 错误码

| 场景 | HTTP | `code` |
|---|---:|---|
| 条目不存在 | 404 | `ENTRY_NOT_FOUND` |
| 标签分类不存在 | 404 | `TAG_CATEGORY_NOT_FOUND` |
| 标签不存在 | 404 | `TAG_NOT_FOUND` |
| 条目标签关系不存在 | 404 | `ENTRY_TAG_NOT_FOUND` |
| 分类名称重复 | 409 | `TAG_CATEGORY_NAME_DUPLICATED` |
| 标签在分类内重名 | 409 | `TAG_NAME_DUPLICATED` |
| 标签仍被条目使用 | 409 | `TAG_IN_USE` |
| 分类仍包含标签 | 409 | `TAG_CATEGORY_NOT_EMPTY` |
| 修改或删除系统“未分类标签”分类 | 409 | `SYSTEM_CATEGORY_PROTECTED` |
| 分类名或标签名非法 | 422 | `TAG_NAME_INVALID` |
| 分类颜色格式非法 | 422 | `TAG_CATEGORY_COLOR_INVALID` |
| 评分不是空或 1 至 10 的整数 | 422 | `RATING_OUT_OF_RANGE` |
| 整体评价超过 10000 字符 | 422 | `ENTRY_REVIEW_TOO_LONG` |

## 7. 分享包边界

### 7.1 本地评价与分享评价

本地条目保存一份 `review`。生成分享包时，用户可以选择：

- `original`：只带本地原评价；
- `new`：只带本次新填的分享评价；
- `both`：同时带本地原评价和本次分享评价。

分享包中分别使用：

- `source_review`：本地原评价的快照；
- `share_review`：本次导出新写的一段评价。

这两个字段都不修改原条目的本地 `review`。分享评价最大 10000 字符。

### 7.2 标签与评分

导出时可以从本地标签中重新选择要包含的标签。每个选中标签携带它在当前条目上的可选评分。

分享包不保存 Tag 的持久化 `share_id`。包内使用只在本包有效的 `tag_ref` 连接标签定义和条目标签评分；`tag_ref` 每次导出重新生成，导入后不存入本地数据库。

导入标签时：

1. 用户为每个导入标签选择本地目标分类；
2. 未选择时放入系统“未分类标签”；
3. 目标分类中已有规范化名称相同时，复用本地标签；
4. 复用标签时，不改变本地分类颜色；
5. 分享包中的评分写入接收方导入后的 EntryTag。

标签分类、分类颜色和 `system_key` 都不进入分享包。

### 7.3 临时派生条目

分享整个条目时，可以直接生成分享快照，不创建临时条目。

只分享一个条目中的部分资源时：

1. 用户选择一个或多个资源，可以形成单文件条目，也可以形成一组文件条目；
2. 系统创建隐藏的临时派生条目；
3. 临时条目可编辑标题、类型、资源、要分享的标签和分享评价；
4. 临时条目不进入正常列表、搜索结果和统计；
5. 分享包写入并校验成功后，再询问用户“删除临时条目”或“保存为本地条目”；
6. 分享失败或取消时删除临时条目；
7. 保存为本地条目时把 `lifecycle_state` 从 `temporary` 改为 `library`；
8. 保存、删除临时条目都不会修改原始条目及其资源。

如果保存临时条目：

- 选中的标签和评分复制到派生条目；
- `share_review` 非空时成为派生条目的本地 `review`；
- 没有 `share_review` 时使用 `source_review`；
- 原始作品的 `review` 保持不变。

## 8. 跨模块交接

### 对成员一：数据与存储

- 增加 TagCategory、Tag 和 EntryTag 表及约束；
- 给 Entry 增加 `review` 字段；
- 为分类名称和标签的规范化名称建立唯一约束；
- 提供 Alembic 迁移，不使用 `create_all()` 作为最终方案。

### 对成员二：条目与资源

- 在 Entry 模型、创建/修改请求和响应中加入 `review`；
- 条目删除不得删除原始资源文件；
- 分享临时派生条目的实现不得绕过条目服务的数据规则。

### 对成员四：检索与展示数据

- `rating_min`、`rating_max` 调整为 1 至 10；
- 标签筛选参数继续使用 `category_id`、`tag_ids`；
- 条目评价文字可参与关键词检索，但是否进入索引需在 T12 确认。

### 对成员五：分享包

- 将标签评分范围从 1 至 5 更新为 1 至 10；
- 移除 Tag 持久化 `share_id`，改为包内临时 `tag_ref`；
- 增加 `source_review`、`share_review` 和评价模式；
- 增加临时派生条目、删除或保存的选择流程；
- 包中不包含 TagCategory 和分类颜色。

### 对成员六：界面与交互

- 一个条目只显示一个整体评价输入框；
- 每个标签显示可选 1 至 10 分控件；
- 分类使用本地颜色；
- 分享页支持标签重选、资源拆分和评价模式选择；
- 分享完成后显示删除或保存临时条目的选择。

## 9. 验收条件

- 分类名称和标签名称执行大小写不敏感的唯一性校验。
- 同一标签名可以在不同分类中存在。
- 同一分类中不能存在两个同名标签。
- 条目可以关联多个标签，每个标签最多一个 1 至 10 分评分。
- 标签允许没有评分。
- 每个条目最多一份整体评价文字。
- 删除正在使用的标签返回 409。
- 删除非空分类返回 409。
- 系统“未分类标签”不能删除。
- 分享时可重新选择标签并选择原评价、新评价或两者。
- 分享包不包含分类、分类颜色或持久化标签 `share_id`。
- 部分资源分享会生成隐藏临时派生条目。
- 分享成功后可以选择删除临时条目或保存为正式本地条目。

## 10. 变更规则

本契约冻结后，字段、接口、错误码、评分范围或分享边界发生变化时，必须先更新对应 Issue，并通知成员一、二、四、五、六、八。不得只修改代码而让文档、分享包和测试继续使用旧规则。
