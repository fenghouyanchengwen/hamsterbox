# 技术架构

## 总体结构

发布版本是一个进程，包含 GUI 主线程和 FastAPI 服务线程。启动器先启动后端并等待健康检查，再创建 PyWebView 窗口；关闭窗口时停止 Uvicorn 并等待线程结束。

```
PyWebView 原生窗口
  └─ Vue 3 + TypeScript 页面
       ├─ HTTP/JSON：业务数据
       └─ JS 桥：原生能力

FastAPI 应用服务层
  └─ SQLAlchemy 仓储层
       └─ SQLite library.db
```

## 边界

| 边界 | 允许承担的职责 | 设计要求 |
|---|---|---|
| HTTP 数据面 | 条目、资源、标签、评分、检索、分享包、设置、健康检查 | 可被 HTTPX 测试，形成稳定的 OpenAPI 契约 |
| JS 能力面 | 选择文件、系统打开、打开目录、保存对话框、回收站 | 只暴露原生能力，不重复实现业务逻辑 |
| 应用服务层 | 校验资源、路径、权限、状态和事务 | HTTP 与 JS 桥调用同一层 |
| 数据层 | 条目、资源、标签、评分与迁移版本 | 只存元数据和路径，不存原始媒体 |

## 安全规则

- JS 桥只接收 `resource_id` 等业务标识，由后端查询真实路径。
- 不接受前端传入任意路径后直接执行系统命令。
- 打开可执行文件时保留明确的用户操作和异常提示。

## 共享约定

- 时间统一以 UTC 存储，界面按本地时区显示。
- 文件哈希统一使用 SHA-256。
- 分享包默认不包含原始文件。
