## 3. 发现并修复的问题

| 编号 | 问题 | 处理 |
|---|---|---|
| BUG-DB-01 | 中文 Windows 下 `alembic.ini` 编码错误 | 改为纯 ASCII 配置 |
| BUG-DB-02 | collation 参数位置错误导致模型导入失败 | 把参数移入 `String()` |
| BUG-DB-03 | 带数据升级时字符串写入日期列失败 | 迁移中用文本列保留原值 |
| BUG-DB-04 | 迁移复制数据时表名错误 | 修正临时表名 |
| BUG-DB-05 | CI 把 Windows 盘符转义后触发 configparser 插值错误 | 直接传 URL 对象 |
| BUG-DB-06 | 标签删除使用级联，违反契约 | 改为 RESTRICT |
| BUG-DB-07 | 190 个 pytest 临时文件被提交 | 删除并补 `.gitignore` |
| BUG-DB-08 | 数据层反向依赖应用层 | 记录类型移入 `db/records.py` |
| BUG-DB-09 | 迁移文档缺少用途、负责人和更新时间 | 补齐文档 |
| BUG-DB-10 | 两条测试断言时机错误 | 修正为在 `flush` 阶段断言 |

前六项会直接造成迁移失败或关系被静默删除，属于本阶段价值最高的缺陷修复。
