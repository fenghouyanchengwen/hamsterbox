## 1. Alpha 第一阶段

- 建立 CI 与 Windows 每日预览构建。
- 修复 PyInstaller 未载入 `app.main` 的问题，增加隐式导入并恢复无控制台窗口。
- GitHub Actions Daily runnable preview 构建成功，下载运行后页面显示后端已连接。

## 2. 已确认缺陷

### BUG-A1-01 Windows 预览版无法载入后端模块

状态为已修复并合入 `main`，记录见 PR #21。

### BUG-A2-01 FallbackAdapter 重复注册

`build_registry()` 注册多个 `FallbackAdapter`，`TypeRegistry` 拒绝同类型重复注册并抛出 `ValueError`，导致内置文件类型注册流程无法完成。

复现环境为 Windows、Python 3.14.2，测试项为 `test_built_in_registry_routes_alpha2_file_types`。PR #34 将该用例标记为严格预期失败，当时基线为 `146 passed, 1 xfailed`。最新主线基线已增长为 `161 passed, 1 xfailed`，缺陷仍然存在。

## 3. 构建问题

添加安装程序时，工作流曾因 YAML 重复定义 `run` 无法启动，随后又因运行器缺少 `ChineseSimplified.isl` 导致编译失败。团队修正工作流缩进并移除不可用语言文件后，Daily runnable preview 运行 #28 构建成功并生成预览包和安装程序两个制品。

## 5. 出口判断

Windows 安装程序构建和 3 台同版本设备安装链路通过，第一阶段打包启动问题已关闭。当前不能宣称所有 Alpha 场景均已验收，原因是：

- 适配器注册缺陷仍未修复；
- TC-01 至 TC-08 没有实际结果；
- 安装设备数量已达到 3 台，但只覆盖同一个 Windows 版本；
- 分享包功能仍在独立分支，尚未进入主线完整场景。
