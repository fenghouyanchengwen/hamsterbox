## 五、已知缺陷

### BUG-01：重复注册 FallbackAdapter 导致注册表构建失败

- 发现日期：2026-11-09
- 测试用例：`test_built_in_registry_routes_alpha2_file_types`
- 复现环境：Windows，Python 3.14.2
- 实际结果：调用 `build_registry()` 时抛出 `ValueError: 适配器重复注册: FallbackAdapter`，注册表构建失败。
- 相关位置：`backend/app/adapters/registry.py:27`；由 `backend/app/adapters/bootstrap.py:26` 触发。
- 严重程度：待与组长评估
- 当前状态：已复现，待定位并修复
- 备注：这是自动化冒烟测试结果；不能据此推断图片、视频、电子书的手工场景测试已经完成。
