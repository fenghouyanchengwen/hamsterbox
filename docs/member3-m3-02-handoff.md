## 3. 关键接口约定

条目标签读取响应：

```json
{
  "entry_id": 1,
  "tag_id": 2,
  "tag_name": "动作",
  "category_id": 3,
  "rating": 9,
  "created_at": "2026-11-07T08:00:00Z",
  "updated_at": "2026-11-07T08:00:00Z"
}
```

写入评分：

```http
PUT /api/entries/1/tags/2
Content-Type: application/json

{"rating": 9}
```

评分允许为空，表示条目已带该标签但尚未评分。
