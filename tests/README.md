# 测试说明

## 职责

覆盖接口、数据库、应用服务、桌面桥接和前端主流程，保证多人合并后主链路仍可运行。

负责人：成员八，各模块负责人补充本模块用例。

## 测试分层

| 层级 | 工具 | 覆盖 |
|---|---|---|
| 领域与校验 | pytest | Pydantic 校验、枚举、评分边界 |
| 应用服务 | pytest + 内存仓储 | 事务、冲突、状态判断 |
| 接口 | pytest + HTTPX / TestClient | 请求响应、错误码、分页 |
| 数据库 | pytest + 临时 SQLite | 迁移、外键、唯一约束、索引 |
| 前端 | Playwright | 列表、详情、评分、导入预览 |
| 桌面桥 | pytest + 假桥 | 参数校验与异常转换 |

## 核心用例

### 条目与资源

- 新建、编辑、移出库。
- 一个条目关联多个文件。
- 文件被移动后显示缺失。
- 移出库不删除磁盘文件。

### 标签与评分

- 标签名称、颜色、是否启用评分。
- 标签重名返回 409。
- 同一 entry 与 tag 只能有一条关联。
- 评分 0、6、1.5 返回 422。
- 未启用评分的标签写入分数返回 422。
- 删除仍被引用的标签返回 409。

### 检索

- 关键词命中标题与简介。
- 单标签筛选。
- 多标签 AND / OR。
- 评分区间边界。
- 分页与排序。
- 1000 条数据下的响应时间基线。

### 分享包

- 导出不含原始文件。
- 包结构符合 schema。
- 哈希匹配成功与失败。
- 冲突条目预览。
- 导入确认前不写入数据库。

## 运行

```powershell
pytest
pytest tests/api -q
pytest --cov=backend/app --cov-report=term-missing
```

## 夹具约定

- 每个测试使用独立临时目录和临时 SQLite。
- 不读取成员真实收藏目录。
- 测试文件由测试自己创建，结束后清理。
- 分享包样例放在 `tests/fixtures/`。
